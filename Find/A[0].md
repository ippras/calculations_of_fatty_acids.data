# Позиционное распределение ЖК в TAG масел (орехи, семена, соя и др.)

Подборка работ, где ЖК определены отдельно по позициям триацилглицерола (sn-1, sn-2, sn-3 или sn-2 против sn-1,3), в основном по панкреатической липазе (TAG → sn-2-MAG).

Дата подборки: 24.11.2026.

**Как собрано.** Общий веб-поиск, не прямые запросы к API Europe PMC, Crossref и Semantic Scholar. Наличие таблиц sn-1,3 / sn-2 подтверждено по отрывкам только там, где это явно указано (✔). В остальных случаях нужна проверка по полному тексту.

Условные обозначения:
- **Полный** — состав sn-1, sn-2 и sn-3 по отдельности.
- **sn-2** — состав sn-2 (MAG) плюс общий состав TAG; sn-1,3 считается.
- ✔ — таблица видна в найденном тексте.

## Методические замечания

- Липаза даёт только sn-2. Средний состав sn-1,3 считается из состава TAG и sn-2: sn-1,3 = (3·TAG − sn-2) / 2 для каждой ЖК.
- Разделить sn-1 и sn-3 можно только стереоспецифическими методами (Grignard + DAG-киназа, хиральная ВЭЖХ и т. п.).
- Панкреатическая липаза медленнее гидролизует ДГК, γ-линоленовую кислоту и некоторые другие кислоты; возможна миграция ацила. Для таких масел цифры sn-2 брать осторожно.

## Пробелы

Не найдены доступные работы с таблицами по липазе для миндаля, макадамии, бразильского ореха, кешью, кунжута и подсолнечника. Для этих объектов чаще встречаются только MS-данные (раздел 5).
